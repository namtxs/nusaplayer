# @nusaplayer/plugins

Optional extras that sit on top of `@nusaplayer/ui`.

```bash
npm i @nusaplayer/core @nusaplayer/ui @nusaplayer/plugins
```

```js
import { Playlist, Chromecast, AirPlay, ad, vttThumbnails } from '@nusaplayer/plugins'
```

```html
<script src="https://cdn.jsdelivr.net/npm/@nusaplayer/plugins@latest/dist/index.min.js"></script>
```

Per-plugin UMD files also exist: `playlist.min.js`, `chromecast.min.js`, `airplay.min.js`, `ad.min.js`, `vttThumbnails.min.js`.

| Plugin | Docs | UMD |
| --- | --- | --- |
| Playlist | [Playlist](/docs/plugins/playlist) | `NusaPlaylist` |
| Chromecast | [Chromecast](/docs/plugins/chromecast) | `NusaChromecast` |
| AirPlay | [AirPlay](/docs/plugins/airplay) | `NusaAirplay` |
| Pre-roll ad / VAST | [Ad](/docs/plugins/ad) | `NusaAd` |
| VTT thumbnails | [VTT thumbnails](/docs/plugins/vtt-thumbnails) | `NusaVttThumbnails` |

Playlist requires `@nusaplayer/ui`. Chromecast / AirPlay add a control when the browser supports them.
